# Axiom — установщики

Axiom — офлайн-приложение для составления школьного расписания.
Здесь публикуются готовые установщики; исходный код хранится отдельно.

Скачать последнюю версию: **[Releases → Latest](https://github.com/Ravva/Axiom-releases/releases/latest)**

| ОС | Файл |
|---|---|
| Windows 10/11 | `Axiom_<версия>_x64-setup.exe` (рекомендуется) или `.msi` |
| macOS (Apple Silicon M1 и новее) | `Axiom_<версия>_aarch64.dmg` |
| macOS (Intel) | `Axiom_<версия>_x64.dmg` |
| Linux | `.AppImage` с зависимостями для МОС 12 (любой дистрибутив), `.deb` (Ubuntu/Debian) |

Установщики не подписаны сертификатами:
- **Windows** — в окне SmartScreen «Подробнее» → «Выполнить в любом случае».
- **macOS** — при первом запуске правый клик по Axiom → «Открыть» (или `xattr -cr /Applications/Axiom.app` в Терминале).

Установленное приложение обновляется само (Windows, macOS, AppImage): при запуске появится предложение обновиться,
проверить вручную — «Настройки → Обновления». Пакеты `.deb` обновляются установкой новой версии.
