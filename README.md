# Axiom — установщики

Axiom — офлайн-приложение для составления школьного расписания.
Здесь публикуются только готовые установщики; исходный код не публикуется и
распространяется отдельно. Приложение проприетарное: см. [LICENSE](LICENSE).

Скачать последнюю версию: **[Releases → Latest](https://github.com/Ravva/Axiom-releases/releases/latest)**

| ОС | Файл |
|---|---|
| Windows 10/11 | `Axiom_<версия>_x64-setup.exe` (рекомендуется) или `.msi` |
| macOS (Apple Silicon M1 и новее) | `Axiom_<версия>_aarch64.dmg` |
| macOS (Intel) | `Axiom_<версия>_x64.dmg` |
| Linux | `.AppImage` с зависимостями для МОС 12 (любой дистрибутив), `.deb` (Ubuntu/Debian), `.rpm` (МОС 13 и новее, ROSA, Fedora) |

Установщики не подписаны сертификатами:
- **Windows** — в окне SmartScreen «Подробнее» → «Выполнить в любом случае».
- **macOS** — при первом запуске правый клик по Axiom → «Открыть» (или `xattr -cr /Applications/Axiom.app` в Терминале).

Установленное приложение обновляется само (Windows, macOS, AppImage): при запуске появится предложение обновиться,
проверить вручную — «Настройки → Обновления». Пакеты `.deb`/`.rpm` обновляются установкой новой версии.

## Сборка (для разработчика)

Здесь живут workflow'ы: **Build** (сборка установщиков), **Publish** (публикация
релиза) и **Web** (выкладка сайта). Исходники закрыты — берутся из
`Ravva/Axiom` по токену `SOURCE_TOKEN`; в закрытом репозитории Actions не
работают (исчерпан лимит кредитов GitHub), поэтому всё живёт здесь.

Релиз запускается тегом сюда:

```sh
git tag -a vX.Y.Z -m "Axiom X.Y.Z"
git push origin vX.Y.Z
```

Тег с таким же именем должен быть и в закрытом репозитории — оттуда берутся
исходники версии. Дальше Build собирает все платформы, Publish проверяет
файлы и публикует релиз (Latest), Web пересобирает сайт.

Вручную: Actions → Build → Run workflow (поле `tag` — тег в `Ravva/Axiom`).
Отдельная платформа: `platforms` (windows, macos-arm, macos-intel, linux).
Пробная сборка без релиза: `dry` — установщики попадут в артефакты запуска.
